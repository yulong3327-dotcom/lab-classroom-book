# 开放实验室 · 桌面实验册版

走近实验台，点击桌上的 3D 实验册。翻开后可从目录选择物理或化学实验，查看器材和实验内容。物理详情也可打开电学自由画布。

触控用左侧摇杆移动、滑动转头，右侧按钮用于跳跃和冲刺。电脑用 WASD 移动、鼠标转头、空格跳跃、Shift 或双击 W 冲刺、C 下蹲。面向实验册时也可按 E 翻书。

电学实验沿用 4b5c67d。制氧实验采用本地预览 8026 对应的 db66254。
